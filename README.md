Whiskr 🐾

An AI-powered Product Information Management (PIM) platform

Whiskr helps businesses manage product catalogs, identify incomplete product information, and improve product data quality. Its AI assistant aims to generate product descriptions and SEO suggestions, allowing users to review changes before saving them.

✨ Key Features

Centralized product catalog management

Product search and filtering

Product data quality checks

AI-assisted product description and SEO suggestions, where implemented

Review and approval workflow for proposed product updates, where implemented

🛠️ Technology Stack

Frontend: React + Vite

Backend: Node.js + Express

Database: MySQL, if configured and connected

AI: AI-assisted product intelligence
